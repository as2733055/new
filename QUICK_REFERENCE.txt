## 🆘 TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Can't access app | Check: docker-compose ps |
| Backend error | Run: docker-compose logs backend |
| Can't send message | Refresh page, check connection |
| Database issue | Run: docker-compose down -v && docker-compose up -d |
