## ⚡ EMERGENCY HOTLINE (Quick Fixes)

### System won't start
```bash
docker-compose down
docker system prune -f
docker-compose up -d
```
→ See [EMERGENCY_DEPLOYMENT.md](EMERGENCY_DEPLOYMENT.md#troubleshooting)

### Can't access http://localhost:3000
```bash
docker-compose ps
docker-compose logs frontend
```
→ See [SYSTEM_STATUS.md](SYSTEM_STATUS.md#troubleshooting)

### Backend not responding
```bash
docker-compose logs backend
docker-compose restart backend
```
→ See [EMERGENCY_DEPLOYMENT.md](EMERGENCY_DEPLOYMENT.md#troubleshooting)
