🛡️ Security Features

🔑 Key Exchange

RSA-2048 - Industry-standard asymmetric encryption for secure key exchange.

💬 Message Encryption

AES-256-GCM - Authenticated encryption preventing tampering.

🔐 Zero-Knowledge

Server cannot decrypt your messages. Maximum privacy guaranteed.

👤 Authentication

JWT Tokens - Secure, stateless authentication.

🔒 Password Security

PBKDF2 Hashing - Salted passwords never stored in plaintext.

🌐 HTTPS Ready

Full TLS/SSL support. All communications encrypted in transit.

🔄 How It Works

1

Register

Create an account. Unique encryption keys generated automatically.

2

Connect

Find friends by username or email. See who's online.

3

Encrypt

Type message. Automatically encrypted with recipient's public key.

4

Send

Send encrypted message. Server stores encrypted blob only.

Start with Docker (30 seconds)

cd frontend
npm install
npm start
